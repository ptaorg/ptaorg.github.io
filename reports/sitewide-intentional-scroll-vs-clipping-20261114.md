# 全750URL表示監査・第5段階：実害のあるはみ出しを修復し正常なスクロールを区別

検査日：2026年11月14日  
対象：[PR #179](https://github.com/ptaorg/ptaorg.github.io/pull/179)  
前工程：[A4閲覧・原資料表の操作改善](a4-desktop-table-controls-audit-20261114.md)

## 方法

PR #178の公開コミット`41728c1`から引き継ぎ、sitemapの750URLを1440×1000pxのPC、390×844pxのスマートフォンでChromium検査した。全1,500表示の機械監査を使い、前段階の「警告39表示」をページ別の`audit.json`と実ブラウザの操作検査で精査した。

警告の大半は、(1)表のスクロール枠の内側にある列、(2)720〜1260pxの原本図や資料表、(3)地図枠の外まで描画されるLeafletタイルであり、**画面外の座標を持つこと自体は不具合ではない**。一方、資料本文やCTAがスクロール枠の外に出ている場合は、実際に切れて読みにくくなる問題として別に扱った。

## 修復した箇所

| ページ | 確認した問題 | 対応と確認 |
|---|---|---|
| `key-materials.html` | モバイルで最重要資料カードの本文幅が約415.6pxとなり390pxの画面からはみ出す | `css/pages/key-materials.css`で資料カードを幅358pxの本文列に収めた。ブラウザ検査で画面外要素0 |
| `guide-board.html` | 後半の4段階「年間是正ロードマップ」で後半のカードが画面外へ出る | スマホでは4カードを各324px幅の1列へ変更。各カードの左右端は33〜357pxで、画面幅390px内 |
| `guide-board.html` | 横長の原本図の移動方向が分かりにくい | 横スクロールする図にだけ案内と44px以上の左右ボタンを追加。図の元SVGとサイズは不変。折りたたみ詳細欄を開くと操作が現れ、閉じると自動的に外す |
| `guide-pta.html` | 「全体構造と出口設計」の長いリンクボタンが右404pxまで伸びる | 2つの出口ボタンをモバイル時に1列に並べ、幅100%、改行可能なテキストへ変更。枠外のはみ出し0 |

既存の出典、本文、図ファイル、アンカーID、canonical、資料URL、法的評価、画像原本、送金先は変更していない。

## 原図の操作テストと折りたたみ

一部の図は閉じた`details`内にある。開かないまま非表示のボタンをクリックする誤ったテストを修正し、**詳細欄を開いてから**可視・操作・移動を検証するよう変更した。

- 原本図の横スクロール枠は8件検出され、すべてに視認可能な案内と2ボタン、キーボードフォーカス、`aria-describedby`があることを確認
- 最初の原本図で右に**226px**、左に**226px**移動し、元の位置に戻った
- `markWideDiagrams`は、非表示・折りたたみ中の図に操作を付けず、`toggle`イベントで表示時に初期化する
- 4段階ロードマップの4カードの幅324px、左33px・右357pxを実測
- 原本SVGを強制的に幅390pxへ縮小する方法は採用していない

## 第5段階監査の分類と結果

最初の全数監査は、画面外座標のあるすべての要素と、表内部の横スクロールを一律の警告として数えていた。今回の監査では以下の3類型を区別し、元の`overflowElements`、`textOverflow`、`outsideBreakdown`をすべてJSONに残した。

- **枠外のはみ出し（要修復）**：地図タイルでもなく、画面内に収まったスクロール枠の子孫でもない要素。1件でもあれば自動テストは失敗
- **適正な内部スクロール**：幅が狭い端末で原本の表・画像を保持し、独立した操作可能な領域内を横へ移動できる状態
- **地図タイルの正常なクリッピング**：Leafletの地図枠を超えるタイル座標があっても、地図枠内で切り抜かれる状態

| 指標 | PR #178の旧分類 | PR #179の分類による全数検査 |
|---|---:|---:|
| 監査表示数 | 1,500 | **1,500** |
| 自動検査エラー | 0 | **0** |
| 警告のある表示 | 39 | **0（新分類）** |
| スクロール枠外へのはみ出し | 区別なし | **0** |
| ページ全体の横スクロール | 0 | **0** |
| 文字の小ささに関する警告 | 0 | **0** |
| 画面外座標を持つ表示（生データ） | 警告に算入 | **34** |
| 正常な内部スクロールを含む表示 | 警告に算入 | **35** |
| Leafletタイルを含む表示 | 警告に算入 | **5** |

34／35／5の集合は重なりがあり、合計する数ではない。**警告が39から0になった差の全てがCSSによる実修復ではない。** 読みにくさのある箇所の修正に加え、正常な内部スクロールと地図描画を誤って警告しないよう、検査基準を精密化した結果である。原資料表の内容や地図は隠さず、測定情報を残した。

## 保全と留保

この工程はモバイル表示の品質改善であり、学校とPTAの法的評価や一次資料の改訂ではない。引用・出典・PDF・スクリーンショット・図の原本ファイル、既存公開URL、canonical、アンカー、金融機関情報は変更していない。

Chromium自動検査は全750URLで実施したが、すべてのリンク先や資料内容の真正性検証、各端末実機、SafariやFirefoxの実ブラウザ全数検査、全ページの人手による通読・視覚評価までは含まない。したがって「表示警告0」は、今回の定義した自動検査で**問題が検出されなかった**という意味であり、あらゆる閲覧環境での無欠陥を保証するものではない。
