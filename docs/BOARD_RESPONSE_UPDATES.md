# 教育委員会回答データベース・追補の保守

## 公開範囲と構造

基準mainはPR #116反映済みの `ae01be0131eec54a9537b3cc28d893eeafc20878`。今回の実装は専用ブランチのみ。マージ・本番公開には別途承認が必要。

既存 `data/board-responses.json` の72回答、CSV、JS索引、個別回答HTML・URLはそのまま維持する。今回の受領メールと非公開添付は原文公開の承認がないため、その原文を既存本文配列に混ぜず、確認済みの行政回答要約を `data/board-response-updates.json` に分離した。同じ `board-responses.html` の静的一覧と統合検索で従来本文と追補を探せる。追加のハブは設けない。

追補は67記録。実質回答58（部分回答・該当なし・組織なしの実質回答を含む）、延期・案内・本文未取得等9。実質回答の新規掲載自治体46、既存主体への追補12。新規掲載は初回回答を意味しない。大阪市／大阪府大阪市などの名称は、既存データを変更せず今回の自治体数計数時のみ正規化し、都道府県と主体名の組で数える。従来72回答の主体は正規化後71。合算した実質回答レコードは130で、確定した是正完了数ではない。

日付は回答文書日が確認できた場合にそれを用い、不明な場合は受信日を用いる。受信日は別欄。日光市は回答文中3月31日／受信4月9日、蔵王町は文書7月24日／受信7月28日、西ノ島町は文書7月28日／受信7月29日。座間市の受信は日本時間2月2日（旧台帳の2月1日はUTC日付）。

## 継承した調査と今回の差分確認

2026-10-28作成の掲載準備台帳55記録（未掲載候補42・追補13）と調査報告書を引き継いだ。2アカウントのメール本文と必要な添付を照合。指定ラベル46通・40スレッド、旧ラベル305通を確認。旧ラベルの検索メール表示には23件の欠落があったため、305IDを列挙し欠落スレッドを別途回復した。これは305通全添付の独立精査完了を意味しない。

台帳55記録を再確認し、座間・高根沢・寒川・福津・鴨川の未読添付を解消。文字化けした本文はRFC原文の文字コードを復元して確認した。旧ラベルの必要差分から13回答を追加（海老名市・愛知県・東京都・長野県・高槻市・三戸町・橋本市・浪江町・土佐清水市・姫路市・千代田区・下妻市・秋田市）。両アカウントへの同一返信・転送・再送・パスワード通知は独立回答数に数えない。

## 法的・研究上の表示

行政側の説明は行政回答要約、委員会の検討は研究上の確認事項として別欄。PTAと公立学校・教育委員会の主体を区分し、事務帰属、学校側の所掌事務・権限、個人情報保護法61条、69条の順で検討する。本人同意・委任・校長指示・職専免を公法上の処理権限の代用としない。規程の存在・当該行為への適用・適法性は区別する。

基本資料：個人情報保護委員会「行政機関等編」5-1・5-5。
https://www.ppc.go.jp/personalinfo/legal/guidelines_administrative/

## 再生成と検査

公開用JSONを更新後、`node scripts/generate-board-response-updates.js` を明示実行する。原文・署名・連絡先・Gmail ID・添付ID・取得トークンは入れない。公開フィールドの許可リストと既存JSONのSHA256保全を `check:board-updates` で検査する。

`npm test` に追補整合検査を接続。`scripts/test-board-updates.mjs` はPC1440px・スマートフォン390pxで検索、論点・回答状況、0件、解除、URL再読込、従来72件の個別ページ、JavaScript無効時の静的本文を確認する。GitHub Actionsでも同テストを実施する。
