# 全国PTA制度・運用研究マップの更新

## 正本と役割

`data/research-municipalities.json` が自治体研究ノートの正本です。`data/schema/research-municipalities.schema.json` が形式を定め、`scripts/check-research-map.js` が形式、ID、出典参照、比較対象、公開済み内部リンクを検査します。研究内容は静的HTMLへ出力するため、JavaScriptなしでも本文と学校一覧を読めます。

既存の `data/schools/` と `archive/` は学校別資料の正本です。学校のデータ、本文、資料公開状態を研究マップ側へコピーしません。研究用索引は既存学校データから生成します。ピンは自治体・都道府県の概略位置であり、学校の所在地、問題件数、違法性を示しません。

## 自治体を追加する

1. 一意の英数字・ハイフンIDを決め、`/research/{id}.html` を研究ページURLとします。既存ID・URLは変更しません。
2. 都道府県名と2桁コード、自治体名・種別、別名、概略座標と座標の説明を登録します。学校の所属先を表す `schoolMunicipality` は既存学校データの `municipality` と完全一致させます。都道府県立学校を所在地の市立学校へ結び付けません。同名自治体・学校は都道府県との組で区別します。
3. `summary`、`system` に資料で支えられた本文を記述し、出典を `sources`、時系列を `timeline`、既存記事を `articles`、未解明事項を `unknowns` に登録します。資料が不足する場合は不足を明記し、空のひな形を完成扱いにしません。
4. `legal` は主体の分離、事務の帰属、学校側の権限、個人情報保護法61条、69条、会計・服務、総合評価の7項目順とします。行政の説明と当委員会の分析を本文で区別します。
5. `themes` は資料との関係が説明できるテーマだけを登録します。制度採用・違法性の認定欄ではありません。`flags` の `confirmed` は出典で確認した場合に限り、未確認は `unconfirmed` とします。改善措置の発出と実施完了を混同しません。
6. `comparisons` に比較先の自治体IDを登録します。各出典の `verification` に原本確認と既存記事内の引用確認のどちらかを明示し、`updated` は今回の研究整理日として更新します。

## 資料・行政回答・研究記事を追加する

`source.id` は自治体内で一意とし、`timeline.sourceId` から参照します。資料名、発行主体、日付、原本または公開済み記事URL、確認状況を揃えます。原本に未到達ならその旨を記します。新しい行政回答は既存の回答公開手順を通し、その公開済みURLを研究データから参照します。研究記事は既存の本文を移設・改稿せず、`articles` に追加します。

公開前確認中のPDF・画像、内部Drive URL、ローカルパスは登録しません。未公開資料の所在がわかる場合も資料名・未確認事項の本文にとどめ、ダウンロードリンクを作りません。個人情報・口座・印影・QR等の確認と原本の公開承認は、研究データ追加とは別の既存手順です。

## 学校資料を追加する

従来の学校別アーカイブの手順とIssue #71の方針に従い `data/schools/` を更新します。研究側で学校一覧やピンを手入力しません。自治体と学校の所属関係を確認したうえで再生成すれば、既存ページへのリンクが研究ノートと学校資料モードへ反映されます。資料目録型の学校を、研究評価型へ自動変換しません。

## 生成・検証

編集前に最新mainの `npm test` を実行し、既存障害を把握します。データ編集後は以下を実行します。

```bash
npm run generate:all
npm test
git diff --check
git diff --stat
```

`npm test` の生成物検査は別の一時ディレクトリで再生成して比較し、作業中のファイルを書き換えません。新しい研究ページは通常のサイトマップとサイト内検索へ収録されます。

PCとスマートフォンで地図、研究／学校資料切替、検索、各フィルター、学校へのリンクを操作します。Leafletやタイルを遮断した場合とJavaScript無効時も一覧・静的本文へ到達できることを確認します。学校JSON件数・内容、既存URL、原本ファイルと公開状態の差分を確認し、PRへ記載します。PR作成後はSite checksの結果を確認します。マージと本番公開は明示承認後に行います。

既存資料館に所在のみがある地域は `data/research-catalog-regions.json` に保持しています。学校JSONや研究ノートが登録された場合は所属自治体を照合し、重複ピンを作らず研究データを優先します。学校が未登録の地域も初期一覧から消しません。この所在一覧は公開可否未確認の原本への新規リンクを持たず、既存資料館へ接続します。


## 2026年10月26日・全国横断一次調査の追加

`data/research-survey-20261026.json` にライブラリー保管の「全国自治体別一覧.xlsx」（自治体別一覧シート）から抽出した48主体の公開用索引があります。`scripts/generate-research-map.js` が48主体の調査一覧を静的HTMLとして研究マップ内に出力します。`js/research-map.js` は検索と絞り込みのみを担うため、JavaScript無効時にも48主体の概要と公開用リンクを読めます。既存の29地域・569校とは異なる母集団です。

- 48主体中、一次資料該当部分を確認したのは39主体。公式本文確認・原本保存未了2主体、検索本文のみ6主体、候補資料1主体。
- 固定探索対象は47都道府県＋20指定都市の67主体で、原本確認33主体。全国全件の検証完了を意味しません。
- 原本確認は資料該当箇所の確認であって、全校運用、現行制度の完全性、適法性・違法性の認定ではありません。
- 非公表の受領資料に依拠する4主体（静岡県・兵庫県・西宮市・広島市）は、元回答本文・資料ID・メールURL・詳細記述を索引に登録していません。受領資料のZIPと未公開原資料はGitHubへアップロードしないこと。
- 公開URLはExcel記載の公表元URLを抽出したもので現在の到達性を保証しません。原資料公開前には独立した公開可否確認を行います。
- `scripts/check-research-survey.js` による件数、重複、非公表資料URL混入の検査を追加しました。`npm run check:survey` または `npm test` で確認できます。

自治体研究ノート11主体の正本は従来どおり `data/research-municipalities.json`、学校別の正本は `data/schools/` です。全国一次調査索引は調査進捗・出典の補助データであり、本文や評価を機械的に上書きしません。統合の際は都道府県と設置主体を正確に突合します。
