# PTA自治体・学校別評価書：権利・尊厳を起点とする表示プレビュー（v0.1）

## 対象ファイルと保全範囲

この改修は scripts/render-evaluation-preview.mjs とテスト、設計資料のみを追加する。全国研究マップ、全国資料館、自治体研究ノート、学校別アーカイブの本文・URL・PDF、既存の評価ラベルは変更しない。

PR #180にある標準スキルの12評価軸と大崎市パイロットデータを、後続のローカル環境で参照する。12軸の定義をこのサイトPRへコピーしない。両PRは独立しており、サイト側の画面表示は標準スキルの検証・公開承認を代替しない。

## 評価書の読み方

**調査の目的は、保護者と子どもの権利・自由・尊厳を守ること。**

観察事実、権利に与え得る影響、責任主体、法的評価、是正案を別々に表示する。権利侵害の事実と違法性を自動推認しない。未確認は問題なしでも違法でもない。

自治体総合評価書は次を表示する。

1. 母集団、対象校数、資料収集の範囲
2. 自由な加入・非加入、役員就任、家庭事情の私生活保護、子どもの公平な取扱い
3. 教育委員会の規程・要綱・指示と制度設計・監督責任
4. 12軸の学校単位集計。YES、NO、示唆、未確認、判定可能率と異なる分母を区別
5. 学校別報告書へのリンクと調査の限界

学校別評価書は次の6部からなる。

1. 権利・尊厳への影響（被害や法令違反は自動認定しない）
2. 原資料に基づく12評価軸（確認YESは対象行為の存在であって違法判定ではない）
3. 教育委員会（制定・指示・監督）、学校・校長（実施・管理）、PTA（内部決定）の責任分離
4. 法的分析の固定順序：①公私の主体分離 ②事務の帰属 ③具体的な学校所掌事務と公法上の権限 ④その後に個人情報保護法61・69条 ⑤規定の存在・適用・適法性、反証と例外を別々に評価
5. 原資料名、発行主体、対象年度、照合状況。非公開PDF・私有フォルダへのリンクは載せない
6. 追加確認事項と是正すべき主体・行為

市教委の規程が存在する事実は、それ自体で私的PTA業務の公務上の権限を創設しない。教育委員会制度主導型でも学校の実施責任を別途検証し、学校独自型でも教委の監督責任を除外しない。

## 権利・責任・法的分析の補助入力

標準12軸データを上書きせず、任意の別JSONで追記できる。公開前の法的検討資料はローカルだけに保管し、GitHubへアップロードしない。

~~~json
{
  "rights": {
    "sample-school-id": [{
      "interest": "プライバシー・人格的尊厳",
      "status": "事実確認中",
      "observation": "確認事実と資料位置を記載する",
      "impact": "権利への影響と反対解釈を記載する",
      "sourceRefs": [{"sourceId": "document-id", "locator": "p.1"}]
    }]
  },
  "responsibility": {
    "sample-school-id": {
      "educationBoard": {"status":"未確認","basis":"規程・制定者・決裁・指示・監督"},
      "school": {"status":"未確認","basis":"実作業・校長決裁・担当者"},
      "pta": {"status":"未確認","basis":"会則・団体内部決定"}
    }
  },
  "legal": {
    "sample-school-id": {
      "subjectSeparation":"公的学校と私的PTA",
      "taskOwnership":"事務の帰属",
      "publicAuthority":"学校側の具体的な所掌・権限",
      "privacy":"権限確認後、個人情報保護法61条・69条",
      "conclusion":"根拠・適用・適法性・反証の区別"
    }
  }
}
~~~

これは人間が執筆するレビュー用の補助入力であって、自動法的判定エンジンではない。

## 実行方法

本PRはPR #180とは別ブランチのため、以下は標準スキルのファイルが同じローカル作業環境に用意された後のコマンド例。

~~~bash
node scripts/render-evaluation-preview.mjs \
  ai-system/report-standards/pilots/osaki-2026.dataset.json \
  ai-system/report-standards/evaluation-axes.json \
  /tmp/pta-osaki-evaluation-preview
~~~

レビュー用の補助JSONがある場合、最後の第4引数としてそのファイルパスを渡す。

生成ファイルは index.html、metrics.json、schools/(school-id).html。学校25校なら27ファイル。出力先をサイトリポジトリ内部へ指定すると拒否する。生成HTMLは未公開の作業プレビューと明記し、noindex/nofollow/noarchiveを設定する。原資料は、公開URLの接続確認済みで、個人情報を含む場合には匿名化の確認済みの場合に限りリンク化する。

このプレビューはPRブランチやGitHub Pagesへ出力してはいけない。ブラウザ確認はローカルHTTPサーバーで行う。実際の公開は原資料・出典・個人情報・法的分析・Senior review・人間承認が完了した後、別PRで実装する。
