# 大崎市25校・サイト第二次公開：出典と公開境界の記録

公開指示：ユーザーによる「ウェブサイトには反映してんよ。」（2026-11-15）  
公開対象：`ptaorg.com` の自治体総括、全25校の学校別評価、文書存否250記録、検索とサイトマップ。  
データ元：PR #180 のドラフト入力 `ai-system/report-standards/pilots/osaki-2026.dataset.json` および `osaki-document-existence-2026-v2.json`、コミット `781ed6b9867c832bca9f7bf7cf7c9595e9e39186`。これらの非公開元データはmainへマージしない。

## 1．公開用データと守秘

- 新しい公開用の単一正本：`data/osaki-public-2026.json`。対象校25校、固定12軸300記録、文書種別10×25校の250記録を格納。
- 元の出典 `sources[].filePath`、文書存否台帳の `documents[].evidence[]` に記録された非公開保存パス、原本PDF、学校文書の署名・印影、口座情報、個人名は公開用にコピーしない。
- 出典は資料の名称・発行主体・資料ID・頁参照で表示。一般公開されている自治体と宮城県の公式ページ2件のみURLを掲載。
- 個人名を含んだ観察記録は公開用に伏せ字化。確認できた原本の全文公開と、要約ページの公開は別。
- 12軸のYES/NOは制度・行為の記載を表し、違法性・人権侵害の確定認定や点数・順位に変換しない。
- 出典の `direct_checked` は提供された調査データの属性。本公開工程では、提出元が照合済みと記録した全原本983頁を別の担当者が独立再監査してはいない。この限界を各公開ページに表示する。

## 2．対象学校と数値

- 2026年度現存校：25校（小14、中9、義務教育学校2）。下伊場野小学校は2026年3月31日廃止のため含めない。
- 学校別開示資料は現存23校と学校教育課、220件983頁。古川西小中学校と鹿島台中学校は当該資料目録にない。
- 12軸の合計：確認YES **17**、明示NO **3**、示唆 **12**、未確認 **268**、非該当0、矛盾0。母数300。
- 「学校によるPTA会費徴収」の観察YESは **5校／25校（20.0%）**、未確認20校。判定可能校内YES率は5/5=100%であって、市内全校の100%を意味しない。
- 文書存否250件：独立文書14、条項のみ2、内部規程のみ17、開示資料中に確認できない197、学校別資料未開示20、行政の正式不存在決定確認0。
- `data/osaki-document-existence-2026.json` は初版2書類のみの履歴データ。current正本を明示する `supersededBy` を付加し、56頁版の頁位置について注記。旧ステータスを最新評価と読み替えない。

## 4．法的検討の固定順序と未確認事項

1. 学校・教育委員会という公的主体と、任意加入の私的PTAを区別する。
2. 役員選出・会員管理・会費・団体会計が誰の事務かを検討する。
3. 学校側がPTA固有事務を公務として行う具体的な所掌・権限、例外根拠を検証する。校務分掌・内部規程・PTA委任・校長裁量・同意を法令上の権限と混同しない。
4. 上記を検証した後、個人情報保護法61条・69条等を検討する。
5. 条文・内部規程の存在、個別事務への適用、具体的な行為の適法性、反証、是正を分ける。

市規程第12条第3号の団体費除外を考慮し、実口座名義・収納契約・現金の保管主体を確認するまでは地方自治法235条の4第2項の具体的な違反を自動認定しない。

## 6．追加調査の継続

最新の観察記録と現場での収納・加入・選出実績を区別する。本人の加入意思、子どもの不利益、個人情報の目的外利用、現金の法的保管主体、教育委員会の具体的な指示・監督は原本と反証を収集し継続調査する。
