# 実在自治体への適用試験（未公開）

## 大崎市 2026年度：学校名簿25校の固定と田尻中学校の一次資料照合

- 入力: `osaki-2026.dataset.json`
- 母集団: 市立小学校14校・中学校9校・義務教育学校2校の計25校
- 母集団一次資料: 大崎市「大崎市立小学校・中学校・義務教育学校一覧」（2026年6月23日更新）
  https://www.city.osaki.miyagi.jp/shisei/lifescenebetsudesagasu/gakko_kyoiku/7297.html
- 全25校の学校IDと12評価軸を固定（300セル）。田尻中学校の「学校によるPTA会費徴収」1セルが `confirmed_yes`、「学校口座・徴収システムの利用」1セルが `indication`、残り298セルが `unknown`。ほかの学校に確認済みYES/NOはない。
- 田尻中学校の2つの資料を直接確認（2026年11月15日）:
  - `全国資料/大崎市/23田尻中学校/18R8学校集金案内.pdf`、p.1。校長名による2026年5月11日付の「令和8年度学校集金について」。ゆうちょ銀行の口座振替による学校集金を案内。
  - `全国資料/大崎市/23田尻中学校/19R8学校集金内訳通知用.pdf`、p.1。「令和8年度学校集金内訳表」No.1 PTA会費1,500円、No.2 PTA生徒活動援助費2,500円、No.3 PTA安全互助会負担金620円（各学年）。
- 2資料の照合で、**学校集金の案内にPTA会費が組み込まれた事実**は確認できる。ただし振替先口座の所有・名義、決済契約、現金の管理主体、学校側の具体的公法上の権限、個人情報の利用・提供については判断材料が足りない。
- 学校の公務とPTAの内部事務を分離し、事務帰属→学校の具体的所掌と権限→個人情報保護法61条・69条→個別適用と結論の順に独立審査する。会費徴収の確認は直ちに違法性の確認ではない。
- 学校徴収金案内には教職員氏名等が含まれる可能性を考慮して `containsPersonalData=true`、`redactionChecked=false` とした。PDF画像や氏名は当該PRにアップロードせず、公開ゲートを閉じたままにする。
- 鳴子小中学校の学校徴収金資料はファイル名・所在のみの `metadata_only` であり、内容から推測しない。
- 自治体の規程・通知、他校の原資料、例外的公法根拠、法的レビュー、公開承認は未完了。

### 集計結果の読み方

学校によるPTA会費徴収軸の確認YES率は **1/25校=4.0%**。直接判定できた学校の中でのYES率は **1/1校=100.0%** だが、判定可能率は **1/25校=4.0%**。したがって「大崎市の全学校の100%が徴収している」という意味ではない。他11評価軸の判定可能校に占めるYES率は `null`（算定不能）である。
