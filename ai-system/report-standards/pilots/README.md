### `confirmed_no` の3件

`confirmed_no` は資料の欠落では使えない。本データセットの3件はいずれも**当該年度の原本が反対の取扱いを明示**しており、スキーマの `explicitNegative: true` を付している。

- 敷玉小学校 04：「未加入の場合は、個々に係るＰＴＡからの卒業記念品や学年ＰＴＡ行事の補助金等については未加入のご家庭に確認しながらその都度徴収させていただきます」。
- 古川中学校 04：PTA安全互助事業について「全員加入方式のため要保護・準要保護学童の負担金免除はありません」。
- 鳴子小中学校 06：父母教師会通帳の名義が学校長ではなく父母教師会であり、徴収金事務取扱規程第12条第3号も「学校徴収金（学校会計団体の会費を除く）の預金名義人は校長とし」と団体費を明示的に除外している。学校の様式・決裁系統で処理されている事実（軸05・軸12は `confirmed_yes`）とは別の論点である。

### 文書存否は別ファイル
