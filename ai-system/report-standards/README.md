# 自治体・学校PTA評価書：固定制作規格 v1.0.0

このディレクトリは `ai-system/skills/municipal-school-report.md` から呼び出す**品質固定規格**です。共通原則を二重定義せず、`ai-system/CORE_INSTRUCTIONS.md` などを上位正本とします。

## 制作フロー（毎回同一）

1. **収集／原本固定**：自治体・教育委員会通知、学校提供資料、PDF、会則、会費案内、役員選出資料、会計、回答文を文書ID・年度・ページ・原本URL・資料所在・確認日・検証レベル付きで取り込む。Google Driveの「全国資料」リンクは公開原本目録の候補にすぎず、PCローカルの同名フォルダと同一と推定しない。画像だけで全文を確認したと誤記しない。
2. **母集団固定**：学校一覧の一次資料を指定、学校ID・校種を固定し、資料がない学校も全校レコードへ。公立校のみ／市立小中のみなどの範囲は毎回宣言。取得数、分析可能数、調査対象数、全設置数は別々にする。年度が合わない資料は判定不可能とする。
3. **行列化**：全学校×12軸の状態6値と原資料ポインタを入力。観察文、推論、法的結論を分離。PTA文書を学校の行政処分と誤認しない。確認材料がなければ `unknown`、明示的反証があれば `confirmed_no`。単なる欠席、記載欠如、取得不能は `confirmed_no` にしない。
4. **法的レビュー**：Skill本文の5段階順序に固定。各重要な論点は、事実・権限・適用条文・反対解釈・暫定/確定判断を整理。未確認の法令はその旨を明記。委任や同意の存在を公法上の権限の代替にしない。
5. **統計**：`scripts/validate-dataset.mjs` が出すJSONだけを数字の正本とする。入力に算出済み割合を書かない。`confirmed_yes`と`confirmed_no`だけを判定可能校とし、`indication`/`unknown`/`conflicting`/`not_applicable`を分母に混ぜない。
6. **執筆**：自治体概況→制度・通知・行政回答→全体特徴→評価軸別の率（分母併記）→学校一覧→学校別個別評価書→出典一覧→未確認・再調査事項。判定根拠を本文の中で読めるように書く。リスクの件数を自治体/学校の有罪判定に読み替えない。
7. **3層地図**：全国自治体ピン → 自治体総合報告書 → 学校別評価と原本。学校座標を推測しない。地図用データは既存マップのschema/slug/canonicalを確認後に統合。調査のカバー率・最新版を表示。
8. **二重チェック**：構造検査・計算検査・リンク原本検証・引用照合・反証検討・Senior review・人間の掲載承認。実施した作業と未実施作業を別記する。

## 12軸と観察値

正本は `evaluation-axes.json`。12軸の定義・対象文書・「Yes」の意味は変更しない。軸追加や定義変更はバージョンアップ＋全既存評価の再判定を要する。

各学校の各軸の状態：

- `confirmed_yes`：直接確認した一次資料が、その学校・対象年度における対象事実を明示する。評価や違法判定ではなく、**行為/制度の存在の確認**。
- `confirmed_no`：直接確認した一次資料が、対象事実の不存在や採用していない旨を**明示**する。無記載・未収集は該当しない。
- `indication`：断片情報・二次資料・疑義などの示唆はあるが、直接の一次資料で確定できない。
- `unknown`：確認材料不足、調査未了、年代不一致。
- `not_applicable`：校種・制度等の理由で適用対象外と**当該年度の一次資料を直接確認**でき、理由がある。資料IDだけでは不可。
- `conflicting`：当該年度の**直接確認済み一次資料を異なる2件以上**保持し、相反する内容とその出典位置を記録して、どちらかへ勝手に収束しない。機械検査は資料の相反性そのものまでは保証しない。

**適法・違法の二択ではない。** 法的リスク評価には別途制度上の権限と具体的行為の詳細調査が必要。

## 割合の定義と表示

学校数を `N`、ある軸の `confirmed_yes`数を `Y`、`confirmed_no`数を `NO`、`indication`数を `I`、`unknown`数を `U`、`not_applicable`数を `NA`、`conflicting`数を `C` とする。

- `Y+NO+I+U+NA+C=N` を検証器で強制。
- **全対象校に占める確認YES率** = `Y/N×100`（最低限確認された比率であり、実態率の推定ではない）。
- **判定可能校に占めるYES率** = `Y/(Y+NO)×100`。分母0なら`null`表示は「算定不能」。
- **判定可能率** = `(Y+NO)/N×100`。曖昧な公表率や推定値を混ぜない。
- 標本抽出や公開資料限定の調査では「全校の割合」ではなく**調査対象校の割合**と記載し、選択バイアスと回収状況を注記。
- 学校規模で加重しない。児童・会員数の割合、文書数の割合、学校数の割合を混同しない。
- 率は小数1位に丸める。恣意的な編集で割合を更新しない。

## 公開ゲート（停止条件）

公開には「審査した」というチェックボックスだけでなく、レビュー担当者・レビュー日を `publication.reviewRecord` に記録する。法的論考を含む報告書では、法的評価の根拠付き主張と5段階審査の記録が必要。

- 全対象校の学校IDが存在しない、重複がある、12軸に穴がある → 公開停止。
- 出典ID・ページ・対象年度が追えない断定がある → 公開停止。
- `confirmed_yes/no`なのに直接確認した一次資料がない → 公開停止。
- 機微な学校・保護者・児童情報を匿名化・マスキングしていない → 公開停止。
- 法的結論で主体→事務→公的権限→個人情報→例外の順序が分離されていない → 公開停止。
- 資料なしを適正・違法どちらかと断定 → 公開停止。
- 重要な反証・矛盾を隠す、自治体の説明を無検証で公認と扱う → 公開停止。
- リンクの有効性、引用原文、引用箇所の照合、Senior/humanレビューが未了 → 公開停止（構造検証器の成功のみでは解除できない）。
- 既存の法令解説・引用・サイト資料・URLを無断変更する → 公開停止。

## Web公開の既存資産との接続

- 既存の学校別原本資料: `data/schools/<municipality>/*.json`、`archive/<municipality>/<school>/index.html`
- 既存全国地図: `national-archive.html`、`research-map.html`、`data/research-municipalities.json`、`data/map-pins.json`
- **新しい評価済みJSONは既存の学校原本JSONを上書きしない**。原本資料と評価を別データとして持ち、`source ID / URL / page location` で結びつける（下流の表示統合はユーザーが承認した工程で実施）。
- 自治体／学校のURLは既存の恒久URLを優先。新規生成ではslug衝突を検査し、旧URL・anchorを保持する。

## 使い方

```bash
node ai-system/report-standards/scripts/validate-dataset.mjs ai-system/report-standards/fixtures/fictional-city.json --metrics result/metrics.json
node ai-system/report-standards/scripts/validate-dataset.mjs ai-system/report-standards/fixtures/fictional-city.json --publish
```

上記の `fictional-city.json` は架空データであり**公開判定には必ず失敗します**。`--publish`は実在する確認済みデータに限定してください。

定型草稿・目録・地図原案の生成：

```bash
node ai-system/report-standards/scripts/render-draft.mjs path/to/municipality.json result/draft
```

生成された文書には未記述箇所・法的確認待ちの表示が残るため、そのまま公開しません。

最初のコマンドは構造と数値の検査であり、人間による法的な最終承認ではない。`--metrics` を付けても構造検証が不合格の場合は集計JSONを新規出力しない。既存の出力ファイルが残っている可能性があるため、後続工程は検証コマンドの終了コード（0は成功、非0は不合格）を必ず検査する。後者は機械で検査できる公開条件とレビューの記録を検証する。利用者承認がない公開実行は行わない。
