# PTA学校別・証拠中心レポート制作スキル v1.2.0

正本：`ai-system/skills/municipal-school-report.md`、`ai-system/report-standards/legal-screening.json`、`assets/pta-parent-report-policy.mjs`。

## 成果物と用途

自治体・学校ごとに同じ視覚規格・法的審査順序を使用した、保護者が理解できる報告書を作る。主役は**確認できた事実→影響→法律上の争点→最低限の適正化措置→改善要求**で、集計と長文は下部のアコーディオンへ保持する。

現行の大崎市25校のサイト実装：
- `assets/osaki-evidence-report.js`（学校別UIの表示コード・事実文・証拠画像の個別設定）
- `assets/osaki-evidence-report.css`（見本画像の赤い警告帯／大きな証拠欄／右側説明欄／詳細展開）
- `assets/pta-parent-report-policy.mjs`（自治体に依存しない色と法令・最低限措置の判定。Nodeとブラウザで共用）

任意自治体の法令審査台帳JSONから同じ構成の**未公開HTML草稿**を作る：
`node ai-system/report-standards/scripts/render-parent-school-report.mjs data/any-municipality-screening.json /tmp/pta-parent-drafts`。
出力は `index.json` と `schools/<schoolId>.html`。公開URLや原本の改変・GitHubへのcommit・deployは行わない。草稿は法的・出典・画像公開の個別審査後に限り公開する。

## 固定された四つの状態色

| 色 | 内部値 | 保護者に表示する意味 | 誤表示を防ぐ条件 |
|---|---|---|---|
| 赤 | `urgent` | 早急な調査・改善が必要 | 学校による会費徴収やPTA内部事務関与、本人の意思に反する選出の仕組み等が対象年度の具体的資料で確認済み。違反確定ではない |
| 黄 | `review` | 重要な確認と改善検討が必要 | 示唆・不一致・制度条項や原資料の検証待ち |
| 灰 | `unknown` | 資料不足・判断保留 | 無記載・未開示・未照合。問題なしとは判定しない |
| 青 | `verified` | 主要項目の適正を資料で確認 | **8領域の積極的な一次資料の適正確認**とレビュー責任者・年度・出典位置が揃い、矛盾や疑義がない場合だけ |

**確認済みの12評価軸「YES/NO」とは別概念。** 特に `confirmed_no` は「学校が徴収していないと明示した資料」など行為の観察値であり、その学校の全分野の適法性を立証しない。資料が開示されない学校に青を付けてはいけない。

青の8領域：`voluntaryJoining`、`feeClaimAndCollection`、`schoolTaskSeparation`、`personalData`、`officerConsent`、`staffDuties`、`moneyCustody`、`childEqualTreatment`。すべてに当該年度の `verified_compliant`、`verification: direct_checked`、`sourceRefs[{sourceId,locator}]` が必要。PTAによる独自徴収又は無会費の確認も必要。レビュー文書に `schoolId`、対象年度、責任者、レビュー日を入れる。**対象年度・調査範囲外までの保証は行わない。**

## 法令の表示と「最低限必要」

- 既存15項目の法令適用表を固定正本とし、学校ごとの `legalTopics` に接続。`legalTopics` にない条文や法的責任を勝手に付け足さない。原資料に法的検討がない学校は「具体的な適用法令の判定資料不足」と表示。
- 保護者向けに法令名・調べる行為・「要件検証中」を表示。**法律違反と認定したような断定表現はしない。** 例：学校徴収なら「学校教育法・地方教育行政法等―学校の所掌事務・公法上の権限」、個人情報の学校保有目的なら「個人情報保護法61条」、目的外利用・提供は「同69条」。
- 法令ごとの `legalTest` は研究者向け詳細に保持。「最低限必要なこと」は当該法令項目の公開用 `minimum` から生成する。会費請求原因とPTA自己管理、学校の権限、個情法61→69、教職員の勤務実態、他人の資金の公的保管の有無・例外をそれぞれ別に扱う。
- 憲法14・26条が直接私人PTAに適用されると断定しない。消費者契約法は消費者契約該当性から、地方自治法235条の4第2項は自治体の保管事実から、刑事・監査・国賠・不当利得は独立要件から検討。
- 校長裁量、学校徴収金規則、委任、本人同意、職専免、慣行では公法上の事務権限が自動的に創設されない。法令がある・適用される・違反するの三層を分ける。

## 画面構成（すべての自治体・学校で統一）

1. **警告帯と学校固有の大見出し**：色は四状態。校名、調査基準日、法令違反確定とは異なることを示す。
2. **左側の証拠欄**：実際の学校・PTA資料の抜粋を優先。赤枠は対象箇所だけ。出典、年度、頁、確認日、公開可否、匿名化の記録を付す。原本がなければ「資料未確認」と表示し、架空の文章や金額を実物のように描かない。文字再構成図は「再構成」と必ず明記。
3. **右側の本文**：「確認されたこと」「なぜ問題か」「適用・抵触が問題となる法律」「適正化に最低限必要なこと」「求める改善」。学校ごとの原資料で異なる文章にする。
4. **補足と詳細資料**：対象の問題タグ、公開上の留保、法令原文、12評価軸、10文書の提出状態、原資料目録、独立した法的要件の検討を `<details>` で表示。
5. **小画面**：2カラムを1カラムにし、法律と改善要求が表・画像に埋もれないようにする。PC・スマホで実ブラウザ検査。

## 必須レビューゲート

- 原資料と表示文言が同一の対象年度・文書・頁に一致する。
- 同意の有無だけから適法を結論しない。主体→事務→所掌・権限→個情法61→69→服務・資金の順。
- 画像を匿名化して、公開前に実画像の氏名、印影、児童情報、口座情報、QRコード、隠しレイヤー、EXIFを再検査。抽出画像をそのままアップロードしない。非公開原本のURLを公開しない。
- 25校なら25校の学校IDを完全一致検査。未知校も灰色で残す。
- 色の自動検査と実機表示検査、法令の原文リンク検査を通し、Senior review・公開の人間承認を記録する。
- 旧ページの本文・アンカー・資料URL・検索用索引・地図接続を破壊しない。
- 公開前の機械検査が成功しても、原資料の法的評価を人手で確定したことにはならない。

## v1.2.1：学校別総評の固定表示位置と文章品質

- 学校別総評は、左側の「確認された証拠資料」欄の**実画像・出典・文字起こしの直下**に設ける。証拠を見た直後に、学校の特徴と問題の構造を読み解ける長文欄とする。右欄の「確認されたこと」「法令」「最低限必要」「改善要求」を置き換えない。
- 総評の文章は、原則3〜4段落で「学校固有の資料で何が確かめられたか」→「どの意味で保護者・公的学校の問題なのか」→「法令適用の順序と残る確認事項」→「適正化の方向」を自然な文章で論じる。短い定型句の寄せ集めにしない。
- 原資料の直接確認が乏しい学校は、空白を埋めるために個別事実を作らない。「資料不足自体の意味」「具体的な次の調査項目」「学校とPTAの情報の保有主体」を一定の文章量で示す。青にする根拠ではない。
- 大崎市の文章正本は `data/osaki-school-overviews-2026.json`。各校 `schoolId / schoolName / title / paragraphs[3以上] / linkedObservationAxes / scope` を保持し、学校別JSが学校IDで接続する。誤接続・欠番・未確認からの断定はテストで公開停止。
- 他自治体の草稿生成時も同じ総評データ（文書ID・年度・頁と照合済みの文章）を入力できる構造を設ける。自動的に事実を補うのではなく、レビュー済み個別文章を差し込む。

## v1.3.0 固定：自治体総合評価と、入会・退会の自由の最優先化

- **最優先の審査は入会しない自由・退会する自由が実際に保障されているか**。入会意思・会員管理・継続・退会意思とその反映を、学校の会費徴収・役員選出の論点に先行して必ず確認する。書面の加入届を民法522条に反して契約成立の絶対条件とせず、代わりにPTAが会員資格をどのような客観的記録・意思表示で特定するかを検証する。
- **ページの階層を固定する**：トップ／地域別索引 → **自治体の総合評価・特徴・改善要求** → 学校別の評価 → 原資料・詳細法令。自治体ページを学校カードのリンク集で代用しない。市の総評（3～5段落）、市全体の入退会の自由の確認状況、地域固有の制度・規程・特徴、優先すべき是正を先に示し、学校別カードはその後に配置。
- 各学校も、上部で「最優先：入会・非加入・退会の自由」を判定可能な資料ごとに表示し、その後に学校固有の証拠・総評・法令・改善要求を掲載する。任意加入の周知と本人の契約成立、退会手続をそれぞれ別の項目として扱う。
- 青は入退会の自由を含む8領域の積極的な適正確認が揃ったときだけとする。入会届・退会規定が開示資料にないことは、契約不存在・強制加入・退会不可能の証明とは扱わない。資料未開示やPTA側の非公開保有は区別する。
- 大崎市の市評価の原本は `data/osaki-municipal-assessment-2026.json`。25校×12軸／10文書種の公開台帳と照合し、入会意思・退会手続の確認0校／25校、該当3種の文書が23校の開示資料で未確認、残り2校未開示、学校徴収資料は5校などの情報を、母数と法的留保付きで説明する。
- 市として求める改善事項は、(1)本人の自由な入会・退会、(2)学校による会費徴収と公法上の権限、(3)役員の承諾と辞退、(4)学校保有個人情報の使用・提供、(5)非会員家庭と児童への配慮の順に原則固定する。ただし自治体固有の原資料に応じて順番以降の重みは調整する。

## 全国地図を上位階層として固定（v1.3.1）

- 保護者の閲覧順序は `トップ → 全国調査マップ → 市の総合評価 → 学校の個別評価 → 証拠資料・詳細法令`。学校レポートを公開しただけでは完成とせず、全国地図・自治体検索・市の総評への導線を必ず検査する。
- 全国地図の正本 `data/research-municipalities.json` に自治体ID、総合評価の公開URL、代表座標、対象年度、根拠・確認限界、学校別評価校数を登録。学校別評価の校数と、別の資料館に登録されている学校数を混同しない。
- 既に制作した自治体総合評価を、研究マップの自動生成で汎用研究ノートに上書きしない。公開前に地図ピン→市の評価→個別校のリンクが途切れていないことを自動検査する。

## 全国地図の表示規格（v1.3.2）―資料の量より選びやすさを優先

- 全国の入口ページは大きな日本地図、自治体名・学校名の単純検索、最新の公表済み自治体評価1件の紹介を主とする。研究テーマや細かい絞り込みを初期表示で列挙しない。詳しい条件は折りたたみ、自治体の一覧は直近公表6地域を優先して表示し、そのほかは展開式にする。
- 画面の文言は保護者の立場で「地図から探す」「自治体の評価を読む」「学校別の調査を見る」とする。「タグ」「ハブ」や制度用語の大きな列挙を画面上部に置かない。詳細資料と全国横断調査48主体は、必要な人が展開して読めるよう保全する。
- 地図の自治体は違反件数や重大度では色分けしない。資料・評価の所在を示すのみで、学校別評価数と資料館の原本登録校数は区別する。入退会の自由が第一順位という大崎市等の評価本文を、地図上の短い紹介で法令違反確定と誤って伝えない。
- 自治体追加・更新後は `data/research-map-index.json` と `data/research-municipalities.json` を照合し、`node scripts/refresh-national-map.mjs` で公開済み全国地図の一覧を更新する。変更がないかは `node scripts/refresh-national-map.mjs --check` で確認する。原本資料、自治体の独自総評、サイト共通ヘッダー・フッターには触れない。
- 学校別報告の公開時には、全国地図→市の総評→学校→実資料のリンクを順に確認し、スマートフォン、地図非表示時、JavaScript無効時、検索と絞り込み、キーボード操作も点検する。


## v1.4.0：教育委員会・市の制度責任と自由・尊厳の保障（2026-11-16）

- 画面の評価層を「市・教育委員会が制定・指示・維持する制度」→「学校・PTAが現実に行った事務」→「本人と子どもの人格・結社・財産・私生活・公平への影響」に分ける。**公的制度の制定主体を学校だけの問題に矮小化しない**。
- 入退会に限らず憲法13条の個人の尊重、21条の結社の自由と非加入、29条の財産権、14・26条の公立学校での公平、19条の条件付き検討を示す。「人間の尊厳」を理念として接続するが、具体的な違法性は証拠と各条文の適用要件に基づく。
- 自治体の要綱・取扱基準・会計基準・学校管理規則は「制定／適用／授権／実施／救済」の5問に区分。本人同意やPTAの委任を権限創設の代替として扱わず、自治体の責任を学校の責任に転嫁しない。
- `institutional-rights-framework.json` の自治体別根拠レベルを公開画面でも区別。先行例：大崎市は既存開示資料で規程第19・20条を確認、大阪市は公式PDFの併徴規定を確認、一宮市は市の制度制定そのものは公開決算書から未立証。
- 12軸の数・校数を自治体責任の件数、憲法違反数、人権侵害件数に機械変換しない。未確認の市でもこの3層の照会・検討を行う。
