# Skill: primary-source-research

## 目的

重要論点について、一次資料を中心に検証可能な証拠束を作る。

## 手順

1. 調査対象、期間、主体、論点を固定する。
2. 公式資料、開示資料、原文書、法令、議事録を優先する。
3. 二次資料は一次資料への導線または反対解釈の確認に使う。
4. 日付、版、対象年度を確認する。
5. 見つからない資料は「未確認」とする。
6. 証拠ごとに何を直接示し、何を示さないかを記録する。

## 出力

- verified facts
- primary evidence
- conflicts / gaps
- items requiring verification
- escalation candidates
