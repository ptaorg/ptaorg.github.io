# Skill: pta-bylaws-membership-rules

## 目的

PTA会則・規約・細則を、会員資格、入退会、意思決定、役員、会費、改正手続の整合性から点検する。

## 発火条件

会則、規約、細則、入会届、退会届、会員規定、総会、規約改正、退会規定等が論点になるとき。

## 確認すべき事実

- 最新版・施行日・改正履歴。
- 会員資格と加入手続。
- 退会・資格喪失・会費の扱い。
- 総会、定足数、議決、委任。
- 役員権限と選出。
- 学校管理職・教職員の位置付け。
- 解散・残余財産・規約改正条項。

## 優先する一次資料

現行会則・規約・細則、改正案、総会議事録、入退会様式、役員規程、会費規程。

## 法的確認ポイント

規約内部の整合、加入意思との関係、団体の意思決定手続、学校側の公的権限と団体役職の区別を確認する。

## よくある誤り

規約に書けば自動的に全保護者を拘束できるとみなすこと、旧版規約を現行版として引用すること、入会と退会だけを直して周辺条項の矛盾を残すこと。

## 出力形式

規約版 / 会員資格 / 入退会 / 会費 / 役員 / 総会・改正 / 学校関与 / 矛盾一覧 / 修正候補。

## Seniorへエスカレーションする条件

会員資格や会費義務の法的効果、規約改正の有効性、非会員への拘束、学校職員の権限に関する重要判断が必要な場合。
