# Skill: pta-structure-analysis

## 目的

PTA案件を横断的に把握し、加入、個人情報、会費、教職員関与、施設利用、社会教育、行政監視のどの専門Skillへ接続すべきかを整理する。専門Skillが発火した場合は、その専門Skillを優先し、本Skillは補助的な全体構造確認に使う。

## 発火条件

PTA運用全体、公私分離、複数論点が絡む案件、または専門Skillのkeywordだけでは論点を十分に特定できないPTA案件。

## 確認すべき事実

- 加入意思表示と会員資格。
- PTAが自ら会員を管理しているか。
- 学校保有情報がPTA事務へ利用・提供されていないか。
- PTA会費を学校納入金と一体で扱っていないか。
- 教職員がPTA内部事務を校務として処理していないか。
- 役員選出に学校情報・学校権限が使われていないか。
- 学校施設・学校資源利用と団体内部事務が混同されていないか。
- 行政支援、委任・契約、情報公開・監査等の論点があるか。

## 優先する一次資料

会則・規約、入退会資料、会費・徴収資料、個人情報関係文書、校務分掌・委任契約、施設利用規程、教育委員会・学校の正式回答、行政の公開資料。

## 法的確認ポイント

本Skillだけで法的結論を確定しない。論点を分解し、該当する専門Skillと `legal-analysis` を併用し、適用主体・根拠・時点・制度区分を一次資料で確認する。

## よくある誤り

PTAという語だけで全論点を一括処理すること、任意加入だけを直せば他の学校関与も解消したとみなすこと、学校とPTAの主体を混同すること。

## 出力形式

論点マップ / 発火すべき専門Skill / 確認済み事実 / 未確認事実 / 一次資料 / 論点間の依存関係 / Senior確認事項。

## Seniorへエスカレーションする条件

複数の専門Skillにまたがる法的評価、主体区分が不明確な案件、個人情報・金銭・公的資源・行政権限が組み合わさる案件、専門Skill間で結論が衝突する場合。
