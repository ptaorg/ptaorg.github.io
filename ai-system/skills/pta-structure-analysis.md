# Skill: pta-structure-analysis

## 目的

PTA運用を、加入、学校との公私分離、個人情報、会費、教職員関与、施設利用の構造から分析する。

## 確認軸

- 加入意思表示はどの時点・方法で確認されるか。
- PTAが自ら会員を管理しているか。
- 学校保有情報がPTA事務へ利用・提供されていないか。
- PTA会費を学校納入金と一体で扱っていないか。
- 教職員がPTA内部事務を校務として処理していないか。
- 役員選出に学校情報・学校権限が使われていないか。
- 学校施設利用と団体内部事務が混同されていないか。

## 注意

個別事案の法的結論は、事実と一次資料を確認した上で `legal-analysis` とSenior reviewへ接続する。
