# Skill: pta-dissolution-restructuring

## 目的

PTAの休会、解散、縮小、任意参加型への再編を、会員意思、資産、契約、個人情報、後継組織との関係から整理する。

## 発火条件

解散、休会、再編、縮小、コア型、後継組織、任意化移行、組織再設計等が論点になるとき。

## 確認すべき事実

- 現行規約の解散・休会・改正手続。
- 会員数と議決要件。
- 残余財産、債務、契約、保険。
- 保有個人情報・名簿の処分。
- 学校が代替事務を引き取らないか。
- 後継組織への自動移行の有無。
- 会費・口座・資産の締め処理。

## 優先する一次資料

会則・規約、総会議事録、決算・資産台帳、契約書、保険資料、個人情報規程、再編案、学校・教育委員会との協議文書。

## 法的確認ポイント

団体内部の意思決定、資産・債務処理、契約終了、個人情報の削除・移管、後継組織への加入意思をそれぞれ分けて確認する。

## よくある誤り

名称変更だけで旧PTAの権利義務が当然に移るとみなすこと、全保護者を後継組織へ自動移行すること、個人情報・残余財産処理を後回しにすること。

## 出力形式

現行状態 / 必要議決 / 資産・債務 / 契約 / 個人情報 / 学校との分離 / 後継組織 / 移行手順 / 未確認事項。

## Seniorへエスカレーションする条件

解散・承継の法的効果、残余財産、契約・債務、個人情報移管、加入意思を伴う重要判断が必要な場合。
