# Skill: school-pta-personal-data

## 目的

公立学校等が保有する児童生徒・保護者情報をPTA事務に利用または提供する場面を、目的、主体、経路、継続性ごとに確認する。

## 発火条件

個人情報、名簿、氏名、学級、住所、連絡先、口座、役員歴、学校からPTAへの提供、PTA事務への学校情報利用が論点になるとき。

## 確認すべき事実

- 情報を保有している主体と利用している主体。
- 取得時の利用目的とPTA利用との関係。
- 学校内部利用か、PTAへの外部提供か。
- 対象者、項目、時期、頻度、提供先、保存期間。
- 同意の有無と取得方法。
- 反復継続する定例運用か、個別臨時の取扱いか。
- 非会員情報が含まれるか。

## 優先する一次資料

利用目的通知、個人情報ファイル簿等、同意書、提供記録、学校・教育委員会の事務文書、PTA名簿、運用要領、個人情報保護委員会等の公式資料、現行法令。

## 法的確認ポイント

適用主体、利用目的の特定、目的内利用・目的外利用、外部提供、同意その他の根拠、継続的運用の根拠を現行制度で確認する。条文番号は一次資料で再確認してから用いる。

## よくある誤り

「同意を取れば常に足りる」と先に結論づけること、学校内部利用とPTAへの提供を混同すること、PTA加入者と児童生徒全員を同一母集団として扱うこと。

## 出力形式

データフロー / 保有主体 / 利用目的 / 提供先 / 根拠資料 / 同意の位置付け / 非会員影響 / 法的未確定点 / 是正候補。

## Seniorへエスカレーションする条件

適法・違法判断、目的外利用・第三者提供の評価、非会員情報の反復利用、同意の有効性、学校とPTAの主体区分に争いがある場合。
