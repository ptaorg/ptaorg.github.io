# Skill: website-edit

## 目的

既存サイトを必要最小限の差分で安全に修正する。

## 作業前

必ず次を明示する。

1. 対象ファイル
2. 変更方針
3. 変更しない範囲

## 手順

1. 既存実装と生成元を確認する。
2. 最小差分で修正する。
3. 既存本文、URL、アンカー、資料導線を不用意に壊さない。
4. 必須チェックを行う。
5. 表示影響があればPC幅とスマートフォン幅を確認する。
6. 変更ファイル数と未実施確認を正確に報告する。

## Git

commit、push、PR、mergeはそれぞれ別の副作用として扱い、ユーザーの指示とツール権限に従う。
