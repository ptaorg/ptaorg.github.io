# Skill: personal-data-purpose-ledger

## 目的

個人情報ファイル簿、利用目的、事務登録簿その他の管理文書と実際のPTA関連情報処理が一致しているかを確認する。

## 発火条件

個人情報ファイル簿、利用目的、目的外利用、事務登録簿、保有個人情報、旧条例様式、更新されていない台帳等が論点になるとき。

## 確認すべき事実

- 文書の名称、版、作成日、最終更新日。
- 現行制度上の位置付け。
- 記載された利用目的・対象者・項目・提供先。
- 実際の学校・PTA運用との一致。
- 旧条例・旧審議会根拠が残っていないか。
- 廃止・変更後の事務が反映されているか。

## 優先する一次資料

個人情報ファイル簿、事務登録簿、利用目的通知、現行条例・規則、移行資料、教育委員会の運用文書、実際の提供・利用記録。

## 法的確認ポイント

現行法制で必要な利用目的・管理文書との整合、旧制度からの移行、実運用と記載の不一致が法的評価に与える影響を確認する。

## よくある誤り

古い台帳の存在だけで現行根拠があるとみなすこと、記載上の目的と実際の利用を照合しないこと、旧制度の審査・同意を現行制度へそのまま持ち込むこと。

## 出力形式

文書ID / 版・更新日 / 記載目的 / 実運用 / 不一致 / 旧制度残存 / 要確認根拠 / 修正候補。

## Seniorへエスカレーションする条件

目的外利用、旧制度依拠、実運用と台帳の重大不一致、個人情報保護法上の適法性判断が必要な場合。
