# Skill: school-fee-collection

## 目的

PTA会費を学校が徴収・口座振替・未納管理・返金・送金する運用を、会員資格、徴収主体、資金経路、学校事務との分離から確認する。

## 発火条件

PTA会費、学校徴収、学校納付金、口座振替、抱き合わせ、未納管理、返金、PTAへの送金等が論点になるとき。

## 確認すべき事実

- 誰が請求対象者を決定するか。
- 会員確認より前に徴収対象化していないか。
- 引落口座、収納口座、会計主体、送金先。
- 学校徴収金とPTA会費が同一請求・同一システムか。
- 未納者照合、督促、返金を誰が行うか。
- 学校側の根拠規程・委任・契約の有無。
- PTAが自己徴収できる仕組みの有無。

## 優先する一次資料

徴収案内、口座振替依頼書、学校徴収金規程、会計規程、委任・契約書、会費台帳、学校・教育委員会回答、PTA会則・予算決算。

## 法的確認ポイント

公的事務と私的団体の徴収事務の区分、会員資格と支払義務の前提、学校口座・徴収システム利用の根拠、関連する自治体規程・財務規則等を確認する。

## よくある誤り

「保護者全員から取っているから学校徴収金」と扱うこと、徴収技術上の便利さを権限根拠とみなすこと、入会確認と会費請求の順序を逆にすること。

## 出力形式

請求対象決定 / 徴収主体 / 資金経路 / 未納・返金処理 / 根拠規程 / 会員資格との接続 / 個人情報利用 / 是正候補。

## Seniorへエスカレーションする条件

支払義務、学校による私金処理、学校口座・公的システム利用、未納管理、法的権限や公私区分に関する重要判断が必要な場合。
