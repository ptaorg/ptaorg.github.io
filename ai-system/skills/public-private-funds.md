# Skill: public-private-funds

## 目的

公金、私金、学校徴収金、PTA会費、学校口座等の資金区分を明確にし、徴収・保管・支出・送金の根拠を確認する。

## 発火条件

公金、私金、学校徴収金、PTA会費、学校口座、預り金、補助金、送金、返金、会計区分等が論点になるとき。

## 確認すべき事実

- 資金の法的・会計上の帰属主体。
- 徴収、保管、支出、承認、監査を誰が行うか。
- 使用口座の名義と管理者。
- 学校徴収金との区分。
- PTA資金を学校が預かる根拠。
- 補助金・委託料等の公金との混在有無。

## 優先する一次資料

学校徴収金規程、財務規則、口座資料、会計簿、PTA決算・予算、補助金交付資料、委任・契約書、監査資料。

## 法的確認ポイント

資金の帰属、公的機関による私金取扱いの根拠、学校口座・公的会計との区分、預り・送金・返金の権限を当該自治体の規程を含め確認する。

## よくある誤り

学校が扱う金銭をすべて学校徴収金と呼ぶこと、私金だから公的規律と無関係とみなすこと、口座名義と実質管理者を確認しないこと。

## 出力形式

資金種別 / 帰属主体 / 徴収・保管 / 口座 / 支出・送金 / 根拠規程 / 混在リスク / 是正候補。

## Seniorへエスカレーションする条件

公金・私金区分、学校口座利用、預り・送金の権限、監査・財務規則違反の可能性など重要な金銭判断を伴う場合。
