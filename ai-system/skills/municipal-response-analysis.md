# Skill: municipal-response-analysis

## 目的

自治体・教育委員会・学校の回答を、質問との対応関係と根拠の有無から分析する。

## 手順

1. 質問項目と回答項目を1対1で対応させる。
2. 回答、事実認定、法的根拠、運用説明を分ける。
3. 未回答、論点ずらし、主体の混同、旧制度依拠を抽出する。
4. 学校判断と教育委員会判断を区別する。
5. 根拠資料の名称・日付・所管を確認する。
6. 他自治体比較は制度・年度・母集団の違いを明示する。

## 出力

- answered
- partially answered
- unanswered
- supporting basis
- contradiction / follow-up point
