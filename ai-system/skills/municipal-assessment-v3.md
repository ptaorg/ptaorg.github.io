# PTA自治体総合評価・制度責任・是正進捗管理スキル v3.0.0
制定: 2026-11-16

## 適用と正本
自治体名で総評の制作・更新・学校別の再評価を求められたら必ず起動する。対象は一宮市、大崎市、厚木市を含む全国の自治体。単なるCSSやリンクの補修には必須ではない。
- 本ファイルは**全体ワークフロー**の正本。基礎評価の正本 `ai-system/skills/municipal-school-report.md`、証拠探索手順 `ai-system/skills/municipal-investigation-pipeline.md`、固定12軸 `ai-system/report-standards/evaluation-axes.json`、文書10種類・15法令・権利審査 `ai-system/report-standards/` を上書きしない。
- 既存の公開原文、静的本文、証拠資料、URL、アンカー、全国地図を保全し、差分による局所更新を原則とする。
- ここに定める法的手順は「観察の優先順序」とは別。**法的評価の入口は主体の分離と事務の帰属**である。総評の読みやすさのために最初に任意加入の自由を表示することは、法的な検証順序を逆転させない。

## 0．基準日・母集団と資料の公開属性
対象年度／調査基準日／校種／設置校の学校ID集合／母集団根拠／入手資料と未収集資料を決める。原本の閲覧権限と公開可否を個別管理し、Gmail・Driveから取得した非公開メール本文・住所・電話・印影・未加工画像等を公開リポジトリへアップロードしない。
成果物：対象範囲宣言・調査台帳・公開／非公開の区分。

## 1．私的保有資料の先行調査（必須）
- 接続された**全ての利用可能な**Gmailアカウントで、自治体名、教育委員会、学校名、部署、メールドメイン、件名、表記揺れによる送信／受信／転送／下書き／添付の検索を実施。スレッド全体を読み、前後の質問を含め、前回の回答から何が変わったか照合。検索結果のページネーションを完走したか記録する。
- Google Driveの自治体フォルダ、開示決定・不存在決定、回答、PDF、通知、要綱、学校別資料、旧版を検索。名称検索がヒットしない資料があるためフォルダも確認。各資料の原本位置と検索対象を明記。
- 重要なメールや文書は日付・発信主体・資料ID・原文箇所・添付・回答済み論点を記録。未取得は「検索で確認できない」であり、行政記録の不存在とはしない。全国一斉送信のCC/BCCに自治体名があるだけでは個別照会と扱わない。
成果物A：Gmail/Driveの検索履歴、照会・回答・添付の時系列台帳、争点別回答管理。

## 2．制度と会費徴収の根拠の先行調査（必須）
- 自治体公式サイト、例規集、教育委員会の通知・手引・ガイド・マニュアル、学校徴収金・準公金・公金外現金の規程、学校納入金の案内、教職員校務分掌、収納委託／決済システム仕様、議会会議録、旧版の制度も調べる。
- 特に **委任・受任／委託契約／保護者同意／校長承認／学校会計／団体費／代理徴収**を条件にPTA会費の学校徴収を許容・指示する条項を抽出。
- 文書のタイトルだけでなく、制定主体、決裁日、発出日、適用校、実施年度、該当条文・頁と原文、改正／廃止、学校への通知、一次URLを記録する。
- 「文書存在→当該学校への適用→学校の具体的な権限→現実の徴収・保管・送金→各行為の適法性」を分ける。自治体が作成した制度については**自治体・教育委員会の制定・指示・監督・改正責任を独立に評価**する。
成果物B：自治体制度原本台帳、根拠文書・通知の版管理、徴収経路・資金フロー。

## 3．委任・準委任・委託の独立審査（必須・飛ばせない）
1. **方向と当事者**を確定する。「PTA→学校／校長／教職員」の受任か「学校→PTA」の業務委託か。PTA会長／校長の署名が**組織を代表するのか私個人なのか**、締結権限、委託事務の具体的内容と対価・期限・責任を確認する。
2. **私法上の性質**を判別する。民法643条の法律行為の委任か、656条の事実行為の準委任か、それ以外の契約か。名称に「委任」と書いてあるだけでは法的性質を決めない。契約成立・有効性も原資料と要件で判断する。
3. **私法上の効果と限界**を区別する。契約が当事者間の業務内容、善管注意義務、費用負担、報告義務、民事上の損害責任を整理する場合はあり得る。しかし、それだけで学校・自治体の法令上の所掌事務・公法上の権限、教職員の公務、他人の現金の公的保管、学校保有情報の目的外使用、PTA会員契約、第三者の権利は**創設・適法化されない**。
4. **独立した公法上の根拠を要求**する。学校が担う行為ごとに具体的な法令・条例・適法な授権と適用事実、例外を先に審査する。校長裁量、校務分掌、学校徴収金規則、職専免、保護者の同意、慣行、PTAの委任を代用品にしない。例外の可能性を調べず「契約があるから直ちに違法」「私人だから絶対不可能」と断定しない。
5. **受任を理由にした責任転嫁を検証**する。学校長が「委託契約ありなら学校長が責任」と説明した場合、民事上の危険負担・契約責任の説明か、公的資源の使用根拠の説明かを分ける。公法上の権限を問われて契約条項だけを示したなら未回答として残す。
6. **逆方向の委託も別件として扱う**。学校本来の業務をPTAに委託する場合、学校業務としての根拠、必要性、利用目的、個人情報保護法上の委託に伴う監督義務等を独立審査し、PTA自身の会員管理等の私的事務と混同しない。PPC2026年3月の公立学校・PTAリーフレットを参照。

参考法令：民法643・644・645・656条 <https://laws.e-gov.go.jp/law/129AC0000000089> ／地方自治法235条の4第2項 <https://laws.e-gov.go.jp/law/322AC0000000067> ／PPC <https://www.ppc.go.jp/files/pdf/202603_school_pta_pd_point.pdf>。

**禁止する誤った結論**：
- 「契約が存在するので学校徴収は適法」
- 「契約が無効なので会費債務はすべて不存在」
- 「委任契約は私法上も一切意味がない」
- 「公的主体の関与が一つでもあればPTA自身の事務はすべて違法」
成果物C1：方向・契約当事者・公法上の授権・服務・個情法・現金保管・会員資格・資金の実態を一行ずつ評価した委任審査表。

## 4．法的審査の強制順序
**①主体分離 → ②事務帰属 → ③市・教委の制定責任と学校の所掌事務／公法上の権限・例外 → ④個人情報保護法61条 → ⑤69条（2項の臨時的例外は個別要件） → ⑥服務・財務会計・会費債務・民事契約 → ⑦人格的尊厳・結社しない自由・財産・プライバシー・児童の公平・各救済の独立要件。**
法令「存在」「適用」「充足」「適法」の四層を混同しない。根拠不明を「根拠不存在確定」と読み替えない。憲法の私人間直接適用、刑事責任・国賠・住民監査請求も個別要件に即して審査する。
成果物C2：自治体制度・学校の運用・権利の3層審査、対立資料・反証。

## 5．改善の時系列評価（批判だけにしない）
- 全ての通知・回答・規程・調査・改訂・学校実施を時系列につなげて、旧通知と現行方針、文書間の不整合、撤回・是正の有無を区別する。
- 進捗の6段階：①問題未認識・従来運用、②問題認識・調査、③権限の整理と方針転換、④正式な制度・通知の改正、⑤全校での運用実施、⑥結果の検証と再発防止。**段階が進んだことは肯定的に評価し、段階を飛ばして改善完了としない**。
- 同じ自治体に「評価すべき前進」「未解決の論点」「次の検証事項」を併記。問題を指摘した当方の働きかけが改善の原因であることは直接の根拠なしに断定しない。
- 厚木市：2026-03-30の代理徴収条件付き通知→2026-04-09の法的位置付けはないとの回答→2026-10-26の自己徴収を含むガイドライン策定方針。改善の方向を評価し、旧通知の改廃・新規程の制定・学校での実施・内部利用への調査拡大は独立して確認する。
成果物D：年月日・現行性・進捗段階・実証資料・正の評価・未解決を保持する時系列改善台帳。

## 6．学校別の評価と公開形式
- 全設置校と研究対象校、資料あり・対象年度該当・未確認・評価完了を分ける。学校ごとに固定12軸・10文書・15法令、本人の加入意思、PTAの会員記録、徴収経路、学校保有情報、教職員、資金、非会員児童の扱いを照合する。
- 保護者向けに見出し・改善優先度・学校固有の証拠・何が確認されたか・必要な改善を主に示し、専門家向け詳細資料は残す。未評価校を「適正（青）」にしない。原資料画像はマスキングと出典特定を必須とする。
- 市の総評は「**過去の制度責任／評価すべき改善／未解決と要求**」を読みやすく示し、学校・市・PTAの責任を混合しない。
成果物E：全校評価、権利との接続、学校個別総評、資料画像マニフェスト。

## 7．公開と検証
全国地図→市総評→学校別→証拠を接続。原本、従来本文とアンカーを保全し、サイト共通CSS・生成元を確認。Xカード（og:image、title、description、twitter:card、画像応答・実プレビュー）、PC・スマホ、本文の左右余白、学校名、表組み、地図、リンク、アンカーを公開実URLで確認する。
`npm test`、`git diff --check`、実機ブラウザ、原文照合とSenior／humanレビューの各記録を残す。コードコミットだけで公開済み、メタタグがあるだけでX表示成功と称しない。
成果物F：変更差分・版・承認・公開後検証証跡。

## 8．停止条件・機械ゲート
- Gmail／Drive／公式制度資料の検索、原本照合、学校別固定規格が未完了なら **正式完成不可／暫定**。
- 委任・準委任を含むのにC1審査が欠ける、公法権限と私法上の効果を混同する、行政の改善の根拠・段階を特定しない、市の責任と学校の行為を混同するなら **法的審査不合格**。
- 公開後ブラウザとXカードを確認していない場合は **公開検証未完了**。一部が未確認でも調査事実に基づく暫定ページはその状態を表示して公開可能だが、完成認定は禁止。
- 機械検査は真正性や法的結論の承認を代行しない。最終公表・公開変更は `AGENTS.md` の人間承認条件を優先。
- 機械ゲートの契約は `ai-system/report-standards/municipal-v3-gates.json`、判定器は `ai-system/report-standards/scripts/validate-municipal-v3.mjs`。実験用の入力やGmail原文はGitHubに置かない。
