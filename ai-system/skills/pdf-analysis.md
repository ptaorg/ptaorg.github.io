# Skill: pdf-analysis

## 目的

PDFを本文テキストとページ画像の両面から確認し、重要箇所をページ単位で根拠化する。

## 手順

1. 資料名、作成主体、日付、版、総ページ数を確認する。
2. テキスト抽出だけで重要な表・図・注記を判断しない。
3. 重要ページはページ画像でも確認する。
4. 引用・数値・表はページ番号と対応させる。
5. OCRは他の方法で読めない場合の最終手段とする。
6. 抜粋だけで資料全体の結論を決めない。

## 出力

- document identity
- important pages
- verified quotations / figures
- visual findings
- unresolved or unreadable parts
